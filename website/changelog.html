릴리스 노트

OpenTask에 새로 생기거나 바뀐 것들을 여기 정리합니다.

정식 첫 릴리스 전입니다. 서명 · 공증이 끝나고 다운로드 가능한 빌드가 올라오면, 그때부터 실제 버전 태그를 기준으로 이 페이지에 릴리스가 쌓입니다. 아래는 지금까지 소스에 구현된 기능을 정리한 사전 요약입니다.

0.1.0

출시 준비 중
  • 태스크 · 서브태스크 · 워크트리 기반 병렬 에이전트 오케스트레이션(태스크 매니저) — 서브태스크 생성 즉시 자동으로 웨이브 지휘 시작
  • 다이어그램 보드로 서브태스크 체인 상태를 조립 라인처럼 요약
  • 캘린더 — 서브태스크 일정 주/월 뷰, 드래그 재조정, 차단 기간
  • 크론잡 — 반복 간격 · 매일 · 매주 예약으로 새 일감 자동 생성
  • 모델 배정 — 작업 종류별(설계 · 코딩 · 리뷰 · QA 등) AI 모델 정책
  • 팀 규칙 — 레포당 자유 텍스트 4칸으로 에이전트 지시문에 실릴 팀 규칙 정의
  • 관제 — 캘린더 · 크론잡 · 설정을 대화로 조작하는 앱 전체 에이전트
  • PR 리뷰 — 코멘트에 리뷰 적용(살아있는 세션에 지시 주입) / 리뷰 항의(GitHub 공개 답글)
  • macOS Electron 데스크톱 앱 셸 — 백엔드를 detached 프로세스로 분리해 앱 종료 후에도 세션 유지
  • electron-updater + GitHub Releases 기반 자동 업데이트 배선(서명 완료 후 활성화)

버전 태그가 붙은 첫 릴리스가 나오면 이 자리에 날짜와 함께 추가됩니다.
