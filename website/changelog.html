Changelog

Release notes

What's new or changed in OpenTask, tracked here.

Signed with Apple Developer ID, not yet notarized. If launching shows an "unidentified developer" warning, right-click the app icon → Open, as described on the download page. Once notarization is in place, it'll launch without any warning.

0.1.9

Latest 2026-09-01
  • Renamed the assistant back to "Hive Mind" (하이브마인드) throughout the app — same brain-in-a-dome icon, reverted name
  • The Task Manager is now framed as a PO/planner that never writes code directly — it plans, dispatches to subtasks, and reviews, with Hive Mind above it and subtasks (developers/designers) below
  • Subtasks can now send lightweight "still working on it" progress check-ins between the start and the done/blocked report, so the conversation log doesn't go quiet for long stretches
  • A subtask's completion report now shows an excerpt directly in the Task Manager's chat log with a button to open the full report, instead of a bare one-line "done"
  • Added a "hide" toggle on task folders in the sidebar — dims a folder in place (collapsed, no expand) without archiving it
  • The sidebar spinner now also reflects the Task Manager's own session activity, not just its subtasks — previously it looked idle while the Task Manager was still planning
  • Fixed the startup loading screen never appearing when the backend connects quickly (a fast local reconnect could load the real app before the loading page ever painted a frame)
  • Fixed the sidebar showing "no tasks in progress" during the first sync instead of a loading indicator, which could be misread as genuinely having zero tasks

0.1.8

2026-09-01
  • The Overmind's icon (sidebar, tab, chat avatar, header) is now the real reference artwork — a brain in a glass dome with a circuit badge
  • The Overmind chat shows small live preview cards for tasks, subtasks, cron jobs, and blocked periods in the side margin as it touches them
  • The Task Manager's conductor↔subtask conversation log is now left/right chat bubbles instead of raw from → to arrows with subtask IDs
  • Silent-stall detection dropped from 15 minutes to 3, and now also covers the conductor session and the Overmind itself, not just subtasks
  • Fixed the app icon not filling its canvas at Dock size
  • Fixed dev mode making the downloaded app appear broken — running the app in developer mode shared the same session lock as the packaged app, so opening the real downloaded app while dev mode was running would silently do nothing instead of showing a window

0.1.7

2026-08-31
  • Critical hotfix — every terminal-based feature (Overmind, Terminal tab, Orchestrator sessions, Task Manager subtasks) crashed instantly with "posix_spawnp failed." in the downloaded app. Root cause: a path-resolution bug in node-pty that only showed up in this app's packaged layout. If v0.1.5 or v0.1.6 crashed for you, this fixes it — no reinstall steps needed beyond grabbing this version.
  • Also fixed a related, load-dependent glitch where the first character of a command sent to a freshly-opened terminal could be dropped (e.g. claude running as laude)

0.1.6

2026-08-31
  • The app now tells you when a new version is out — a small notice appears in the status bar (checking GitHub Releases) and links straight to the download page. Auto-install is still blocked until notarization lands, so this is the reliable way to know for now.
  • Cron Jobs got a redesign — a dense GitHub Actions/Vercel Cron–style table with a success/failed/never-run status icon per row, replacing the old card list
  • New in-browser element picker in the Browser tab — pick any element on the page and copy its selector/HTML, or send it straight to the conductor along with an instruction
  • Fixed a session getting stuck on the "resume from summary" confirmation prompt when reconnecting to a large or old conversation via claude --continue — it's now auto-confirmed, and the sidebar names the exact reason if that window is ever missed

0.1.5

2026-08-31
  • "Assistant" is now "Overmind" — same top-level agent that runs the whole app by conversation (calendar, cron jobs, settings), new name and a new brain-shaped icon
  • Cron Jobs can now run a free-form instruction instead of only creating a fixed task — write what you want done in natural language once, and it runs exactly as written on schedule, with no improvised scope from the AI
  • Fixed the create/update cron job tools, which had never actually worked due to a parameter-parsing bug

0.1.4

2026-08-31
  • Fixed the Assistant and Task Manager always replying in Korean, regardless of your interface language setting — they now match whichever language you write to them in
  • Fixed a bug where running more than one OpenTask instance on the same machine could make their MCP tool registrations collide and cross-talk
  • Fixed dark mode: explicitly selecting "Dark" in Settings (as opposed to following the OS) was leaking light-mode tint colors into progress/success and pending/attention highlights
  • Fixed a flash of light theme before dark theme kicks in on cold start, when dark mode is explicitly selected
  • Fixed a startup crash affecting the Assistant/Task Manager when the app runs straight off a mounted disk image

0.1.3

2026-08-28
  • Fixed the root cause of the black-screen-on-launch bug — the backend health check was polling a route that returns HTML, so it always reported "not responding" even when the backend was healthy within seconds. It now polls the correct JSON health endpoint.
  • Shows a loading screen while starting up, and a real macOS error dialog (Retry/Quit) instead of a silent console log if startup ever fails
  • Goes straight to the main screen even with no repo connected (removed the forced onboarding gate)
  • Cleaned up the repo folder-picker UI
  • Now signed with Apple Developer ID (notarization planned for a future release)

0.1.2

2026-08-28
  • Upgraded Electron 33 → 44 — fixed a renderer crash on recent macOS
  • Fixed several path bugs that only showed up in packaged builds (backend spawn, dependency unpacking)
  • Auto-selects an open port if the default is taken
  • Wired up electron-updater for auto-updates

0.1.1

2026-08-28
  • Attempted a signed & notarized build

0.1.0

2026-08-28
  • Task · subtask · worktree–based parallel agent orchestration (Task Manager) — the wave starts driving automatically the moment a subtask is created
  • Diagram board summarizing a subtask chain like an assembly line
  • Calendar — week/month views of subtask schedules, drag-to-reschedule, blocked periods
  • Cron Jobs — interval, daily, or weekly schedules that auto-create new tasks
  • Model Policy — per-task-type (design, coding, review, QA, etc.) AI model assignment
  • Team Rules — four free-text fields per repo that get folded into every agent's instructions
  • Control — a whole-app agent that manages the calendar, cron jobs, and settings by conversation
  • macOS Electron desktop shell — the backend runs as a detached process so sessions survive quitting the app
