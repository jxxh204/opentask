Changelog

Release notes

What's new or changed in OpenTask, tracked here.

Signed with Apple Developer ID, not yet notarized. If launching shows an "unidentified developer" warning, right-click the app icon → Open, as described on the download page. Once notarization is in place, it'll launch without any warning.

0.1.5

Latest 2026-08-31
  • "Assistant" is now "Overmind" — same top-level agent that runs the whole app by conversation (calendar, cron jobs, settings), new name and a new brain-shaped icon
  • Cron Jobs can now run a free-form instruction instead of only creating a fixed task — write what you want done in natural language once, and it runs exactly as written on schedule, with no improvised scope from the AI
  • Fixed the create/update cron job tools, which had never actually worked due to a parameter-parsing bug

0.1.4

2026-08-31
  • Fixed the Assistant and Task Manager always replying in Korean, regardless of your interface language setting — they now match whichever language you write to them in
  • Fixed a bug where running more than one OpenTask instance on the same machine could make their MCP tool registrations collide and cross-talk
  • Fixed dark mode: explicitly selecting "Dark" in Settings (as opposed to following the OS) was leaking light-mode tint colors into progress/success and pending/attention highlights
  • Fixed a flash of light theme before dark theme kicks in on cold start, when dark mode is explicitly selected
  • Fixed a startup crash affecting the Assistant/Task Manager when the app runs straight off a mounted disk image

0.1.3

2026-08-28
  • Fixed the root cause of the black-screen-on-launch bug — the backend health check was polling a route that returns HTML, so it always reported "not responding" even when the backend was healthy within seconds. It now polls the correct JSON health endpoint.
  • Shows a loading screen while starting up, and a real macOS error dialog (Retry/Quit) instead of a silent console log if startup ever fails
  • Goes straight to the main screen even with no repo connected (removed the forced onboarding gate)
  • Cleaned up the repo folder-picker UI
  • Now signed with Apple Developer ID (notarization planned for a future release)

0.1.2

2026-08-28
  • Upgraded Electron 33 → 44 — fixed a renderer crash on recent macOS
  • Fixed several path bugs that only showed up in packaged builds (backend spawn, dependency unpacking)
  • Auto-selects an open port if the default is taken
  • Wired up electron-updater for auto-updates

0.1.1

2026-08-28
  • Attempted a signed & notarized build

0.1.0

2026-08-28
  • Task · subtask · worktree–based parallel agent orchestration (Task Manager) — the wave starts driving automatically the moment a subtask is created
  • Diagram board summarizing a subtask chain like an assembly line
  • Calendar — week/month views of subtask schedules, drag-to-reschedule, blocked periods
  • Cron Jobs — interval, daily, or weekly schedules that auto-create new tasks
  • Model Policy — per-task-type (design, coding, review, QA, etc.) AI model assignment
  • Team Rules — four free-text fields per repo that get folded into every agent's instructions
  • Control — a whole-app agent that manages the calendar, cron jobs, and settings by conversation
  • macOS Electron desktop shell — the backend runs as a detached process so sessions survive quitting the app
