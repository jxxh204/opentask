릴리스 노트

OpenTask에 새로 생기거나 바뀐 것들을 여기 정리합니다.

Apple Developer ID로 서명은 됐지만 공증(notarize)은 아직입니다. 실행 시 "확인되지 않은 개발자" 경고가 뜨면 다운로드 페이지 안내대로 앱 아이콘을 우클릭 → 열기로 실행하세요. 공증이 끝나면 경고 없이 바로 실행됩니다.

0.1.7

최신 2026-08-31
  • 긴급 수정 — 다운로드한 앱에서 터미널을 쓰는 모든 기능(오버마인드, 터미널 탭, 오케스트레이터 세션, 태스크 매니저 서브태스크)이 "posix_spawnp failed."로 즉시 크래시하던 문제. 원인은 이 앱의 패키징 구조에서만 드러나는 node-pty의 경로 해석 버그였습니다. v0.1.5나 v0.1.6에서 크래시를 겪으셨다면 이 버전으로 바로 해결됩니다.
  • 부하가 큰 환경에서 터미널을 새로 열 때 첫 명령의 앞글자가 씹히던 문제(예: claude가 laude로 실행)도 함께 수정

0.1.6

2026-08-31
  • 새 버전이 나오면 앱이 직접 알려줍니다 — 상태바에 알림이 뜨고(GitHub Releases 확인), 클릭하면 다운로드 페이지로 바로 이동합니다. 공증 전까지는 자동 설치가 막혀있으니, 지금은 이게 새 버전을 아는 확실한 방법입니다.
  • 크론잡 화면 리디자인 — 카드 목록 대신 GitHub Actions/Vercel Cron 스타일의 촘촘한 테이블로, 행마다 성공/실패/미실행 상태 아이콘이 붙습니다
  • 브라우저 탭에 새 요소 피커 추가 — 페이지의 아무 요소나 골라 선택자/HTML을 복사하거나, 지시문과 함께 지휘자에게 바로 전송할 수 있습니다
  • claude --continue로 크고 오래된 대화를 이어받을 때 "요약으로 재개할지" 확인 메뉴에서 세션이 멈추던 문제 수정 — 이제 자동으로 확정되고, 혹시 그 순간을 놓쳐도 사이드바에 정확한 사유가 표시됩니다

0.1.5

2026-08-31
  • "비서"가 "오버마인드"로 이름이 바뀌었습니다 — 캘린더·크론잡·설정까지 앱 전체를 대화로 조작하는 최상위 에이전트는 그대로, 이름과 뇌 형상 아이콘만 새로워졌습니다
  • 크론잡에서 이제 정해진 태스크 생성뿐 아니라 자유롭게 쓴 지시도 실행할 수 있습니다 — 원하는 걸 한 번 자연어로 써두면, 예정된 시각마다 그 문장 그대로 실행되고 AI가 즉흥적으로 범위를 넓히지 않습니다
  • 크론잡 생성/수정 툴이 파라미터 파싱 버그로 실제로는 한 번도 제대로 동작한 적이 없었던 것을 수정

0.1.4

2026-08-31
  • 비서·태스크 매니저가 인터페이스 언어 설정과 무관하게 항상 한국어로만 답하던 버그 수정 — 이제 말을 건 언어에 맞춰 답합니다
  • 한 머신에서 OpenTask 인스턴스를 여러 개 띄우면 MCP 툴 등록이 서로 충돌·혼선을 일으키던 버그 수정
  • 다크모드 수정: 설정에서 "다크"를 직접 고르면(OS 설정을 따르지 않고) 진행/성공, 대기/주의 강조색에 라이트 모드 틴트가 새어 들어가던 문제
  • 다크모드를 직접 선택한 상태에서 콜드 스타트 시 라이트 테마가 잠깐 비쳤다 다크로 바뀌던 깜빡임 제거
  • 앱을 마운트된 디스크 이미지에서 바로 실행하면 비서·태스크 매니저 쪽에서 기동 직후 크래시하던 버그 수정

0.1.3

2026-08-28
  • 실행하면 검은 화면만 뜨던 문제를 근본적으로 수정 — 백엔드 기동 확인이 HTML을 반환하는 경로를 보고 있어 정상 기동해도 항상 "응답 없음"으로 오판하던 버그였습니다. 이제 올바른 헬스체크 경로를 확인합니다.
  • 기동 중 로딩 화면 표시, 기동 실패 시 실제 macOS 에러 팝업(재시도/종료)으로 안내
  • 레포 미연결 상태에서도 곧장 메인 화면으로 진입(강제 온보딩 화면 제거)
  • 레포 폴더 선택 버튼 UI 정리
  • Apple Developer ID 서명 적용(공증은 다음 버전에서 예정)
