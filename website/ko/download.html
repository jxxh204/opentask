소스에서 직접 빌드하기

OpenTask는 오픈소스입니다. 정식 빌드를 기다리지 않고 지금 바로 로컬에서 빌드해 사용할 수 있습니다.

의존성 설치 후 개발 모드 실행

app/ 폴더에서 npm install 이후 npm run electron:dev로 데스크톱 창을 바로 띄울 수 있습니다.

배포용 앱으로 패키징 (선택)

npm run electron:build로 .dmg/.zip을 직접 만들 수 있습니다.

git clone https://github.com/jxxh204/opentask cd opentask/app npm install npm run electron:dev
