Release notes

What's new or changed in OpenTask, tracked here.

Before the first official release. Once signing and notarization are done and a downloadable build is up, releases will start accumulating here against real version tags. What follows is a pre-release summary of what's already built.

0.1.0

Pre-release
  • Task · subtask · worktree–based parallel agent orchestration (Task Manager) — the wave starts driving automatically the moment a subtask is created
  • Diagram board summarizing a subtask chain like an assembly line
  • Calendar — week/month views of subtask schedules, drag-to-reschedule, blocked periods
  • Cron Jobs — interval, daily, or weekly schedules that auto-create new tasks
  • Model Policy — per-task-type (design, coding, review, QA, etc.) AI model assignment
  • Team Rules — four free-text fields per repo that get folded into every agent's instructions
  • Control — a whole-app agent that manages the calendar, cron jobs, and settings by conversation
  • PR Review — Apply a comment (injects into a live session) or Dispute it (public reply on GitHub)
  • macOS Electron desktop shell — the backend runs as a detached process so sessions survive quitting the app
  • Auto-update wiring via electron-updater + GitHub Releases (activates once signing is in place)

The first tagged release will be added here with a date once it ships.
