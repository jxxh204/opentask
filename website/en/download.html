Build it from source

OpenTask is open source. You don't have to wait for the official build — run it locally right now.

Clone the repository

Grab the source with the command below in your terminal.

Install dependencies and run dev mode

From the app/ folder, run npm install, then npm run electron:dev to launch the desktop window directly.

Package it as a distributable app (optional)

npm run electron:build produces a .dmg/.zip directly.

git clone https://github.com/jxxh204/opentask cd opentask/app npm install npm run electron:dev
